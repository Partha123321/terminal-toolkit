# Contributing

Thanks for your interest in improving Terminal Toolkit!

## Ways to contribute

- Fix a bug
- Improve input validation
- Add a small command-line utility
- Improve documentation
- Add tests

## Before submitting

1. Keep each tool focused and easy to understand.
2. Use clear variable and function names.
3. Compile with C++17 and enable warnings where possible:
   `g++ -std=c++17 -Wall -Wextra -pedantic`
4. Update the README if you add or change a tool.
5. Do not commit passwords, API keys, private files, or build outputs.

## Pull request checklist

- [ ] The code compiles.
- [ ] I tested the change.
- [ ] I updated documentation if needed.
- [ ] The change is focused and understandable.
